Дата снимка: 7 сентября 2026 года.  
Контур: production, PostgreSQL в Docker.  
Режим нагрузочного тестирования: **только чтение**.

| Таблица | Полный размер PostgreSQL |
|---|---:|
| `page` | 360 MB |
| `search_index` | 279 MB |
| `assistant_chunk` | 252 MB |

Для pgbench автоматически выбиралась высокочастотная лемма длиной не менее пяти символов. В зафиксированном прогоне использована лемма `агентство`. Сценарий выполнял группировку и сортировку релевантности по таблицам `search_index` и `lemma` с ограничением результата до 10 страниц.

## Почему нет полного дампа

Полный production-дамп нельзя публиковать в открытом GitHub-репозитории: он содержит тексты пользовательских документов, адреса источников, идентификаторы владельцев и данные авторизации. Для доказательности публикуются агрегированные количества, размеры таблиц, схема миграций, исходный SQL-тест и raw-результаты pgbench. Этого достаточно для проверки методики без раскрытия персональных и защищённых данных.
