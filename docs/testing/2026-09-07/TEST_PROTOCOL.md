## 5. Границы сделанных выводов

- HTTP-нагрузка проверяет публичный web-контур и не содержит пользовательских данных.
- SQL-нагрузка выполнялась только на чтение; данные production не изменялись.
- Полный авторизованный RAG-сценарий под многопользовательской нагрузкой не запускался без отдельного staging-контура.
- Для заявления о промышленной готовности необходимо поднять покрытие критических сервисов минимум до 60% и повторить E2E-нагрузку на staging.
